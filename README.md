💜 Violetly

Welcome to your world ✨

Violetly is an Android application featuring a modern, elegant purple-themed design with a welcoming splash screen, login screen, and account creation screen. The app focuses on a clean, simple, and user-friendly experience.


1. Splash Screen

- Violetly app logo
- Purple branding
- Welcome message: "Welcome to your world"

2. Login Screen

- Email and password input fields
- Show/hide password option
- Forgot Password option
- Login button
- Continue with Google button
- Navigation to the Sign Up screen

3. Sign Up Screen

- Full name input field
- Email input field
- Password and confirm password fields
- Show/hide password options
- Sign Up button
- Navigation to the Login screen

✨ Features

- Modern purple and white user interface
- Custom Violetly app logo
- Attractive splash screen
- Login and account creation UI
- Password visibility toggle icons
- Simple and intuitive navigation design
- Consistent colors and rounded UI elements

🛠️ Technologies Used

- Language: Java
- UI Design: XML
- IDE: Android Studio
- Build System: Gradle

🎯 Project Goal

The goal of Violetly is to create a visually appealing Android app with a consistent brand identity and essential authentication screens.

🚀 Future Improvements

- User registration and login functionality
- Forgot password and email verification
- Google Sign-In integration
- Secure user authentication and data storage
